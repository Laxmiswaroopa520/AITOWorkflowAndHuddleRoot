`DisplayLabel` text on rows pointing at `AGT-001` (Sales Agent) -- now has its own catalog ID,
`AGT-016`, per the workbook's own Change Summary (row 60, dated 2026-09-16). It remains "a skill
inside Sales Chat, not a standalone agent" (its own words); only the attribution changed.
